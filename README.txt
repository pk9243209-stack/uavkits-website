UAVKITS.IN website starter
==========================

FILES
- index.html: complete responsive website (HTML, CSS and JavaScript in one file)

HOW TO PREVIEW ON WINDOWS
1. Download and extract uavkits_website.zip.
2. Open the extracted folder.
3. Double-click index.html. It should open in your browser.
4. For editing, install Visual Studio Code (https://code.visualstudio.com/) and open the folder.
5. Open index.html and edit the text/styles. Save and refresh your browser.

IMPORTANT BEFORE PUBLISHING
- Search for REPLACE-WITH-YOUR-EMAIL in index.html and replace it with your actual business email in both the contact details and JavaScript recipient.
- Replace the placeholder city and tagline.
- Verify every product category, service claim, image, and capability matches your actual business.
- Product photos in this demo are external Unsplash URLs and require internet access. Replace them with your own licensed product images where possible.
- The quote form currently prepares an email using the visitor's email app. It does not save enquiries on a server and may not work if the visitor has no mail app configured. For reliable enquiry delivery, connect a form backend/service before launch.
- This is a static website and does not include a product database, login, inventory, checkout, or payment system.

PUBLISHING OPTION
GitHub Pages can host static HTML/CSS/JavaScript from a public repository on GitHub Free and supports custom domains. Start with the official docs:
https://docs.github.com/en/pages
Do not change GoDaddy DNS until the hosting platform gives you the exact DNS records and you have added the custom domain in the hosting settings.
